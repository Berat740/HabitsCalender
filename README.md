# HabitsCalender 📅 [WIP]

> 🚧 **Work in Progress:** This project is currently undergoing a major development phase and architectural revamp. The codebase, features, and user interface are actively being upgraded. 

A privacy-focused habit tracking application built with .NET MAUI. HabitsCalender allows users to build consistent routines with seamless Android Widget integration, keeping all data strictly local and secure.

## 🚀 Current Development Focus

Instead of an immediate release, this repository is currently focused on laying a robust engineering foundation. The current development roadmap includes:

- **UI/UX Redesign:** Transitioning from the initial prototype to a polished, modern, and intuitive user interface.
- **Enhanced Widget Logic:** Upgrading the Android AppWidgets API integration for faster synchronization and better battery optimization.
- **Architectural Refactoring:** Structuring the codebase with a strong modular design to easily support future web or desktop migrations.
- **Data Layer Optimization:** Improving local database queries and storage efficiency.

## ✨ Planned Features

* **Interactive Android Widget:** Mark habits as completed directly from the home screen.
* **Local Data Privacy:** 100% offline functionality. No cloud syncing, no external servers.
* **Progress Tracking:** Visualizing daily consistency and long-term streaks.

## ⚙️ Getting Started (For Developers)

*Disclaimer: As the project is under active development, the `main` branch may occasionally contain experimental or unstable commits.*

### Prerequisites
* [Visual Studio 2022](https://visualstudio.microsoft.com/) (with .NET MAUI workload installed)
* Android SDK (API 31 or higher)

### Installation
1. Clone the repository: `git clone https://github.com/yourusername/HabitsCalender.git`
2. Open `HabitsCalender.sln` in Visual Studio.
3. Restore NuGet packages and build for `net8.0-android`.
